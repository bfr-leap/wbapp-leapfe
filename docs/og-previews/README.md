# OG card preview samples

These are **demo renders** of the Open Graph cards generated by
`server/api/og.get.ts` for shareable LEAP URLs. They exist so we can
visually verify the card design without actually unfurling URLs in
Discord or Slack.

The data is mocked — real cards pull live results from the LEAP Data
Broker via the renderer in `server/utils/og-render-results.ts`.

| File | Mode | Notes |
| --- | --- | --- |
| `results-sample.svg` | `?m=results&...` | Top-6 finishers · podium-medal badges |
| `results-sample.png` | `?m=results&...` | Same, rasterized via @resvg/resvg-js for parity |

Both files render at the canonical 1200×630 OG card size.

These previews are throwaway — safe to delete before merging the
parent branch.
