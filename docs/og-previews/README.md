# OG card preview samples

Visual previews of the Open Graph cards generated by `server/api/og.get.ts`
for every shareable LEAP URL mode. Useful for design review without
having to actually unfurl URLs in Discord or Slack.

The data is mocked — real cards pull live data from the LEAP Data
Broker via the per-mode renderers in `server/utils/og-render-*.ts`.

| Mode | URL pattern | Card content |
| --- | --- | --- |
| `home.png` | `/` (no `m=`) | League name · upcoming races |
| `results.png` | `?m=results&subsession=...` | Top 6 finishers · gaps · points |
| `standings.png` | `?m=standings&league=...&season=...` | Top 5 drivers · power points |
| `driver.png` | `?m=driver&driver=...` | Driver name · 4-cell stats grid |
| `team.png` | `?m=team&team=...` | Team name · roster |
| `track.png` | `?m=track&car=...&track=...` | Track · top 5 fastest laps |
| `season.png` | `?m=season&season=...` | Season · schedule highlights |
| `rulings.png` | `?m=rulings&season=...` | Recent rulings · driver · infraction |

All cards render at the canonical 1200×630 OG card size. Modes not
listed here (`m=profile`, embed modes, admin modes) intentionally fall
through to a brand card.

These previews are throwaway — safe to delete before merging the
parent branch.
